# Vyom X1 5G

Concept brand site for **Vyom X1 5G** — a sub-₹20,000 smartphone positioned against
Realme P4x, iQOO Z10x, Samsung M17e, Poco X7 and Redmi 15 5G in the Indian online segment.

- `index.html` — the complete brand site (self-contained: all product renders are
  embedded as base64 WebP, no external requests).
- Positioning: penetration pricing, never loss-making. ₹18,999 (8+128) / ₹19,999 (12+256),
  ₹17,499 effective after bank offer.
- All product imagery is CGI produced for this concept; specifications are the
  proposed spec sheet, not a shipped product.

Generated as a design/launch exercise.
